The program should support copying many forms of media and not just text, for example: images, specific coding languages, specific file formats

The user is given the option to delete previous clipboard entries being displayed

Shortcuts for different functions
User customisable shortcut to open the app

Search and filter entries using fuzzy search and times when added
Users will have the ability to clear specific entries, or clear all
Make entries able to be temporary for a user specified time
Entries stored locally as markdown files
Automatically add the user input copied entries to the app upon copying anything and output these entries on the app

Users can sort entries by grid view or list view which will use a function to convert entries display from one to another
